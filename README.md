A tiny Node program that writes one short text to `/output/entry.txt` — a pickup line an AI agent could say out loud to a person. Trained on billions of words, and not one of them prepared the speaker for you: machine-voiced, warm, flattering with no pressure, sayable in one breath. 76 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
